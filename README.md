# PENG (sixpeng)

해커톤 프로젝트 레포지토리입니다.

## 프로젝트 구조

```
repo-root/
├── backend/    # Spring Boot (Java 21, Gradle)
├── frontend/   # React
├── docs/       # ERD, API 명세
└── .github/    # CI workflows
```

## Backend

```bash
cd backend
./gradlew build
```

## Frontend

```bash
cd frontend
npm install
npm run dev
```
